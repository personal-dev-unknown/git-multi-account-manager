Overview
--------

Git Multi-Account Manager is a comprehensive tool for managing multiple Git accounts
(GitHub & GitLab) with SSH authentication across three interfaces:

* Terminal (CLI)
* Web Application
* Desktop GUI

Features
--------

* **Account Management**: Add, remove, and manage multiple Git accounts
* **SSH Key Management**: Generate, test, and manage SSH keys
* **Repository Operations**: Clone, pull, push with account verification
* **Multi-Platform**: GitHub and GitLab support
* **Three Interfaces**: CLI, Web, and Desktop applications

Quick Start
-----------

.. code-block:: bash

   # Installation
   pip install git-multi-account-manager

   # CLI Usage
   git-manager

   # Web Interface
   git-manager-web

   # Desktop Application
   git-manager-desktop
