How Git Manager handles SSH URLs

When you use an SSH URL, Git Manager rewrites it to use the account's SSH config host alias. For example, a URL like git@github.com:owner/repo.git for the account with alias work becomes git@github.com-work:owner/repo.git. This makes git use the correct ~/.ssh/config Host entry and therefore the correct private key. 

# ~/.ssh/config entry for the "work" GitHub account
Host github.com-work
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_github_work
  IdentitiesOnly yes
