How SSH key isolation works

Git Manager generates a unique key pair for each account and writes a dedicated Host block to ~/.ssh/config. When you clone a repository with git@github.com-work:owner/repo.git, SSH reads the config and automatically selects the correct private key — no ssh-agent juggling required. 

Host github.com-work
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_github_work
  IdentitiesOnly yes
  Port 22
